# EMBAPALLETS

Sitio web comercial estático de EMBAPALLETS.

## Cambiar imágenes

Las imágenes provisionales están en `assets/images/`. Al incorporar fotografías definitivas se actualiza solamente la referencia correspondiente en `index.html` y en la ficha del producto.

## Contenido modular

- `productos/`: fichas individuales de cada producto.
- `guia-pallets/`: artículos informativos para SEO.
- `css/styles.css`: paleta y estilos compartidos.
- `js/app.js`: navegación móvil e interacción básica.
