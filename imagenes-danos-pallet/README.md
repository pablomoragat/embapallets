# Imágenes de daños en pallets

Archivo fotográfico de referencia de Embapallets para registrar daños, desgaste y condiciones observables en pallets de madera.

## Fotografías archivadas

- **IMG-20261007-WA0039.jpeg**: vista superior de un pallet de madera usado, pintado de azul. Se aprecia desgaste de la pintura, marcas de uso, perforaciones de fijación y manchas superficiales. La fotografía no permite confirmar por sí sola si existe daño estructural.

**Registro:** 9 de octubre de 2026.  
**Archivo:** imagen original JPEG, sin modificación ni reducción de resolución.

Esta carpeta es documental y no está enlazada desde la página comercial. Atención: el repositorio de GitHub es público.
